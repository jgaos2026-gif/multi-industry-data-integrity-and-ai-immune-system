# JGA Universal Integrity Fabric (JGA UIF)

Verification-first, fail-closed platform for multi-industry data and AI integrity.

## Core invariant

**No active state becomes trusted state without verification.**

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest
```

## Scope

This repository is defensive and local-first. It does not include offensive external capabilities.
